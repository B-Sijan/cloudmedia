# CloudMedia

Serverless cloud media sharing platform built using Microsoft Azure.

## Features
- Upload images/videos
- View media gallery
- Edit media metadata
- Delete media
- Azure Blob Storage integration
- Azure SQL Database integration
- Azure Functions backend
- Static Web Hosting
- Application Insights monitoring

## Technologies
- Azure Functions
- Azure Blob Storage
- Azure SQL Database
- Azure Static Website Hosting
- JavaScript
- HTML/CSS
- Node.js

## Architecture
Frontend → Azure Functions → Azure SQL + Blob Storage
